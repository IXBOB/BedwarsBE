## ⚠️ Important Notice — Unauthorized Commercial Use & Tampered Attribution

### 🚨 Unauthorised Modifications & Commercialization by LQworld Studio / 浪柒99
Recently, I discovered that **LQworld** (a studio with **610,000 subscribers** on NetEase’s Minecraft platform) **modified and republished this project without authorization, added monetization/pay-to-win systems (e.g., inscriptions, cumulative top-up rankings),** and **tampered with the author attribution**.  
Their modified release is titled **“铭文起床战争 [联机大厅]”** (“Inscriptions Bedwars [Online Lobby]”) and is **commercially sold** on the NetEase Minecraft platform.

### ❌ Violations of the MIT Open-Source License
This project is open-sourced under the **MIT License**, which allows modification and commercial use, provided the following conditions are met:
- **The original author attribution must be retained.**
- **The full MIT license text must be included.**

However, **LQworld / 浪柒99** did not comply with the MIT license:
- **Altered the original author information**, mentioning the author only in “Special Thanks” rather than providing proper attribution.
- **Did not include the MIT license text**, violating the **attribution clause** of the license.
- **Misled users into believing** the work was independently created by LQworld.
